The totals chain

Everything an Order says about money is either a link in this chain or the breakdown of one link.

line items ──minus discounts──▶ subtotal ──plus shipping, tax, tip──▶ total │ │ │ │ originalTotalSet │ subtotalPriceSet: never │ totalPriceSet: │ per line │ contains shipping or tips │ what was charged

The formulas, in plain words

line value          = originalTotalSet − sum of discountAllocations.allocatedAmountSet

lines before disc.  = sum of originalTotalSet over all lines   (no order field for this)

subtotalPriceSet    = sum of line value over all lines

shipping            = sum of discountedPriceSet over all shipping lines

totalDiscountsSet   = sum of allocations on all lines
                      + sum of allocations on all shipping lines

totalTaxSet         = sum of taxLines.priceSet over all lines
                      + sum of taxLines.priceSet over all shipping lines

totalPriceSet       = subtotalPriceSet + shipping + totalTaxSet + totalTipReceivedSet
                      (leave totalTaxSet out when taxesIncluded is true)

currentTotalPriceSet = totalPriceSet − refunds + order edits
⚠ Three traps
1. totalDiscountsSet includes shipping discounts, but shipping already enters through discountedPriceSet. Subtracting totalDiscountsSet from anything that contains shipping counts the discount twice.
2. lineItem.discountedTotalSet and lineItem.totalDiscountSet leave out order-level and code discounts. Use the allocations.
3. subtotalPriceSet never contains shipping or tips, and contains tax only when taxesIncluded is true. That is why the line value is the natural cashback base.

The query

query OrderMoney($id: ID!) {
  order(id: $id) {
    name currencyCode presentmentCurrencyCode taxesIncluded
    displayFinancialStatus sourceName processedAt
    subtotalPriceSet      { shopMoney { amount } }
    totalDiscountsSet     { shopMoney { amount } }
    totalShippingPriceSet { shopMoney { amount } }
    totalTaxSet           { shopMoney { amount } }
    totalTipReceivedSet   { shopMoney { amount } }
    totalPriceSet         { shopMoney { amount } }
    currentSubtotalPriceSet  { shopMoney { amount } }
    currentTotalDiscountsSet { shopMoney { amount } }
    currentTotalTaxSet       { shopMoney { amount } }
    currentTotalPriceSet     { shopMoney { amount } }
    discountCodes
    discountApplications(first: 10) { nodes {
      __typename index allocationMethod targetSelection targetType
      value { ... on MoneyV2 { amount } ... on PricingPercentageValue { percentage } }
      ... on DiscountCodeApplication { code }
      ... on AutomaticDiscountApplication { title }
    } }
    lineItems(first: 50) { nodes {
      id title quantity currentQuantity isGiftCard taxable requiresShipping
      product { id }
      originalUnitPriceSet { shopMoney { amount } }
      originalTotalSet     { shopMoney { amount } }
      discountAllocations { allocatedAmountSet { shopMoney { amount } } discountApplication { index } }
      taxLines { title ratePercentage priceSet { shopMoney { amount } } }
    } }
    shippingLines(first: 5) { nodes {
      title
      originalPriceSet   { shopMoney { amount } }
      discountedPriceSet { shopMoney { amount } }
      discountAllocations { allocatedAmountSet { shopMoney { amount } } discountApplication { index } }
      taxLines { ratePercentage priceSet { shopMoney { amount } } }
    } }
    transactions { kind gateway status amountSet { shopMoney { amount } } }
    refunds {
      createdAt note
      totalRefundedSet { shopMoney { amount } }
      refundLineItems(first: 50) { nodes {
        quantity restockType
        subtotalSet { shopMoney { amount } } totalTaxSet { shopMoney { amount } }
        lineItem { id }
      } }
      orderAdjustments(first: 10) { nodes { reason amountSet { shopMoney { amount } } } }
      transactions(first: 10) { nodes { kind gateway amountSet { shopMoney { amount } } } }
    }
  }
}

Where smile-core stands today

The current normalizer fetches the order over REST (ShopifyAPI::Order.find) and computes rewardable_total as line items before discounts, minus excluded lines, minus non-shipping discounts, minus refunds: 195.00 → 145.00 → 121.50 → 69.00 on the final order. The cashback normalizer will query GraphQL and use the per-line value instead. Source: app/operations/channel/shopify/shopify_order/{fetch,normalize}.rb.
