Dar contexto ao Claude: o CLAUDE.md

Contexto curado vence contexto despejado. Ensine o repositório uma vez, colha em toda sessão.

Na Lição 01 você aprendeu a dirigir o loop com contexto explícito — mas dado prompt a prompt. Há um contexto que se repete toda sessão: como rodar os testes, o estilo de código, a estrutura do repo. Repetir isso é desperdício. O CLAUDE.md é a memória do projeto: um arquivo que o Claude Code carrega automaticamente no início de cada sessão.1 Esta lição te ensina o que colocar nele — e, mais importante, o que não colocar.

Recuperando a Lição 01: o ciclo Explorar → Planejar → Codar → Verificar. O CLAUDE.md alimenta as duas pontas: dá ao Claude o mapa para explorar mais rápido e o comando de teste para verificar sozinho — sem você reexplicar em cada prompt.

O que é, e como carrega

O Claude Code procura arquivos CLAUDE.md subindo pela árvore de diretórios e os carrega por inteiro no início da sessão.1 A hierarquia se soma (não sobrescreve), do mais amplo ao mais específico:

Organização
Policy
Regra gerenciada da empresa, aplicada a todos.
Usuário
~/.claude
Suas preferências pessoais, valem em todo projeto.
Projeto
./CLAUDE.md
Versionado no repo, compartilhado com o time.
Local
.local.md
Só seu, no repo. Vai no .gitignore.

Um CLAUDE.md numa subpasta não pesa desde o início: ele entra sob demanda, só quando o Claude lê arquivos daquele diretório.1 Comece um projeto com /init — ele analisa a base e gera um CLAUDE.md inicial com comandos de build, teste e convenções.2 Para editar depois, use /memory.2

O que colocar (e o que não)

Coloque o que se repete e é verificável. Comandos de build e teste, estilo de código, convenções de nomes, o layout do repo, o checklist de review.1 São instruções concretas que o Claude confere no próprio contexto.

Não despeje tudo. Procedimento de vários passos vira skill; instrução de uma pasta só vira rule por caminho (.claude/rules/). O CLAUDE.md é entregue no startup — não é config imposta.1

# smile-core ## Comandos - Testes: `smile-cli run-specs ` - Lint: `smile-cli standardrb` ## Estilo Ruby - Sem `.freeze`; prefira `pluck` a `map` - Constantes fora de blocos ## Etiqueta - PRs sempre em draft; título `[COR-XXX]`
⚡ Por que curar (a janela de contexto)
O CLAUDE.md custa tokens em toda sessão. Quanto maior, menos o Claude adere a ele — a regra importante se afoga no ruído. A orientação oficial é manter cada arquivo abaixo de ~200 linhas, específico e conciso.1 Precisa reaproveitar um arquivo maior? Importe-o com @caminho/arquivo (até 4 níveis de importação).1
