Claude Code · Lição 01 · Práticas

Explorar → Planejar → Codar → Verificar

Dirija o agente com contexto explícito, em vez de torcer por um prompt "one-shot".

Você já usa o Claude Code todo dia. A diferença entre um resultado medíocre e um ótimo quase nunca está no modelo — está em como você dirige o loop. O Claude Code funciona como um loop agêntico: reunir contexto → agir → verificar → repetir.2 Seu trabalho de sênior não é escrever o código; é guiar esse loop com intenção. Esta lição te dá o ciclo que faz isso.

O ciclo em quatro fases

1 · Explorar
Ler, não tocar
Em plan mode. Deixe o Claude ler arquivos e tirar dúvidas. Custa quase nada e evita resolver o problema errado.
2 · Planejar
Plano escrito
Um plano de implementação, revisado e editado por você. É seu contrato com o Claude.
3 · Codar
Executar
Só agora edita arquivos, seguindo o plano.
4 · Verificar
Fechar o loop
Dê um sinal que ele leia: testes, build, lint, screenshot.

O erro clássico é colapsar as quatro fases num prompt só. Separá-las é o que troca adivinhação por direção.1

Três práticas concretas

1. Use plan mode para mudanças multi-arquivo. Aperte Shift+Tab duas vezes, peça pro Claude ler os arquivos relevantes e produzir um plano escrito. Revise o plano, edite pra adicionar restrições — e só então mude pra code mode e implemente.1

2. Escope o prompt: arquivos, restrições e saída esperada. Em vez de "adicione testes para foo.rb", diga: "Escreva um teste para foo.rb cobrindo o caso do usuário deslogado. Sem mocks." Aponte para a fonte, não para o conceito.1

3. Sempre dê um sinal de verificação. Testes, script, lint ou screenshot que o Claude possa rodar. Sem isso, ele para quando parece pronto — e você vira o loop de feedback. Com um check, ele roda, lê o resultado e itera sozinho até passar.1

⚡ Por que isso importa (a janela de contexto)
A janela de contexto enche rápido — cada leitura e saída consome tokens; quando enche, o desempenho cai e instruções antigas se perdem.2 As três práticas acima também economizam contexto. Para escalar além de uma sessão: subagents (contexto isolado)3 e skills (conhecimento sob demanda, sem inchar o CLAUDE.md).4

Pratique agora — recupere de memória

Clique na resposta.

1. Antes de editar arquivos numa mudança multi-arquivo (ex.: OAuth), o que fazer primeiro?

2. Você pediu "adicione testes ao pagamento" e faltou um caso crítico. O que faltou?

3. O código parece pronto, mas você não sabe se funciona. Melhor passo?
